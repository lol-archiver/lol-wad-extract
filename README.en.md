# @lol-archiver/lol-wad-extract
![Version](https://img.shields.io/github/package-json/v/lol-archiver/lol-wad-extract?style=flat-square)
[![License](https://img.shields.io/github/license/lol-archiver/lol-wad-extract?style=flat-square)](https://www.gnu.org/licenses/lgpl-3.0-standalone.html)

A League of Legends WAD archive extraction tool. Provides the ability to compute WAD internal path hashes, extract files on demand, and automatically decompress them.

## Basic Example

```javascript
import { hashWAD, extractWAD } from '@lol-archiver/lol-wad-extract';


// --- Compute the hash of a file path inside the WAD ---
const hash = hashWAD('data/characters/morgana/morgana.bin');
console.log(hash); // e.g. 123456789012345n (bigint)


// --- Extract files from a WAD archive ---
const extracted = await extractWAD(
  './Game/DATA/FINAL/Champions/Morgana.wad.client',
  [
    {
      fileInpack: 'data/characters/morgana/morgana.bin',
      fileSave: './saved/morgana.bin'
    },
    {
      fileInpack: 'assets/characters/morgana/hud/morgana_circle_0.tex'
    }
  ],
  { fileZSTD: '/usr/bin/zstd' } // Using custom zstd
);

console.log(extracted[0].saved); // true (fileSave specified, true after file is written)
console.log(extracted[1].buffer); // Original Buffer (if not saved to disk)
```

## Core Concepts

`@lol-archiver/lol-wad-extract` comprises two core functions:

- **`hashWAD`** – Converts an internal virtual path into its corresponding 64-bit hash value according to the League of Legends WAD file hashing rules. This is essential for locating file entries within a WAD.
- **`extractWAD`** – Reads a WAD file, locates the corresponding entries based on a given list of paths, decompresses them, and optionally writes the files to disk.

A WAD file itself is an archive format containing multiple files, with each entry indexed by the hash of its path. This library traverses the WAD’s entry table and extracts only the files you specify, avoiding a full read of the archive.

## Installation

```bash
npm install @lol-archiver/lol-wad-extract
```

This package supports only Node.js environments. It relies on native modules such as `fs`, `child_process` and `zlib`.

## API Reference

### `hashWAD(string, format?)`

Computes the XXHash hash of a WAD internal file path.

- **Parameters**:
  - `string` `{string}` – The file path inside the WAD (e.g. `data/images/champion.png`). **The input is converted to lowercase internally**; please ensure the path matches the format stored in the WAD.
  - `format` `{string}` `optional` – The format of the return value. Possible values:
    - `'bigint'` (default) – Returns the hash as a `bigint`.
    - `'hexpad'` – Returns a zero-padded hexadecimal string with a fixed width of at least 10 characters.
- **Returns**: `{bigint | string}` – The corresponding hash value.

```javascript
const hashBigint = hashWAD('data/characters/morgana/morgana.bin');
console.log(hashBigint); // 16965086179359362018n

const hashHex = hashWAD('data/characters/morgana/morgana.bin', 'hexpad');
console.log(hashHex); // 'eb7017fec89a8be2'
```

### `extractWAD(fileWAD, configsExtractRaw, options?)`

Extracts specified files from a WAD archive.

- **Parameters**:
  - `fileWAD` `{string}` – Path to the WAD file.
  - `configsExtractRaw` `{RawExtractConfig[]}` – A list of files to extract. Each object has the following properties:
    - `fileInpack` `{string}` – Virtual path of the file inside the WAD.
    - `fileSave` `{string}` – Destination path on disk where the extracted file will be saved.
  - `options` `{ExtractOption}` `optional` – Extraction options:
    - `fileZSTD` `{string}` – Path to an external `zstd` executable. If provided, Zstandard decompression is performed by invoking this program via `spawnSync`; otherwise, Node.js’s built-in `zstdDecompressSync` is used.
    - `maxBufferUnzstd` `{number}` – Maximum allowed buffer size (in bytes) when using the external zstd. Defaults to `buffer.length * 16`. Exceeding this size will throw an error.
- **Returns**: `{Promise<ExtractConfig[]>}` – An array of **successfully extracted** configurations (each containing `buffer` and `saved`).

```javascript
const result = await extractWAD(
  './Game/DATA/FINAL/Champions/Morgana.wad.client',
  [
    {
      fileInpack: 'data/characters/morgana/morgana.bin',
      fileSave: './saved/morgana.bin'
    },
    { 
      fileInpack: 'assets/characters/morgana/hud/morgana_circle_0.tex'
    }
  ],
  { fileZSTD: '/usr/bin/zstd' } // Using custom zstd
);

console.log(result.length); // 2 (if both files are found)
```

## Type Definitions

```typescript
// Extraction options
interface ExtractOption {
  /** Path to an external zstd executable */
  fileZSTD: string;

  /** Maximum buffer size (in bytes) allowed when decompressing with external zstd */
  maxBufferUnzstd?: number;
}

// Raw extraction configuration (user input)
interface RawExtractConfig {
  /** File path inside the WAD */
  fileInpack: string;

  /** Destination path on disk after extraction */
  fileSave: string;
}

// Final extraction configuration (includes extraction results)
interface ExtractConfig {
  fileInpack: string;
  fileSave: string;
  
  /** Hash of the file inside the WAD (computed by the library) */
  hashInpack?: string;
  /** Decompressed data Buffer (absent if extraction fails) */
  buffer?: Buffer;
  /** Whether the file was successfully written to disk */
  saved?: boolean;
}
```

## Notes

### External Zstandard Dependency

If a WAD contains Zstandard-compressed entries, you have two options:

1. **Use built-in decompression**: Use Node.js’s `zstdDecompressSync` (`node:zlib`). No external dependency is required.
2. **Use an external `zstd` executable**: Provide the path to `zstd` via `options.fileZSTD`. This can be useful when you want to leverage native performance.

### Hash Calculation

`hashWAD` is based on the XXHash64 algorithm, and the input string is first converted to lowercase. The algorithm matches the way the Riot game client computes WAD entry hashes.

### Passing duplicate fileInpack

If `configsExtractRaw` passed to `extractWAD` contains the same `fileInpack` multiple times, only the last configuration provided will take effect.
